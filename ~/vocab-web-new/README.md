# Vocab Web Application

This is the web component of the Vocab project, designed to help users enhance their vocabulary through daily learning and interactive quizzes.

## Features

- Daily word displays with pronunciation, definitions, and examples
- Mobile-responsive design
- Firebase integration for backend services
- Clean, modern UI for an engaging user experience

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone this repository
```bash
git clone https://github.com/yourusername/vocab-web.git
cd vocab-web
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

## Building for Production

```bash
npm run build
```

## Firebase Configuration

This project uses Firebase for backend services. You need to set up your own Firebase project and update the configuration in `.env` file (see `.env.example` for reference).
