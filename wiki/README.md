### Contributing to the Wiki

We welcome contributions to improve this documentation:

1. Fork the repository
2. Make your changes
3. Submit a pull request with a clear description of your improvements

For detailed guidelines, please see our [Contributing Guide](CONTRIBUTING.md).

When contributing, please follow these guidelines:
- Use clear, concise language
- Include screenshots when explaining UI features
- Follow Markdown best practices
- Verify all links work properly
- Update the table of contents when adding new pages

### Wiki Structure

Each wiki page follows a consistent structure:
- Clear title and introduction
- Logically organized sections with descriptive headings
- Visual aids (images, diagrams) where helpful
- Cross-references to related pages
- FAQ section for common questions (when applicable)

## Keeping Documentation Updated

This wiki is continuously updated to reflect the latest version of Vocab. If you notice any discrepancies between the documentation and the application, please report them by:

1. Opening an issue on GitHub
2. Describing the inconsistency
3. Including the app version you're using
